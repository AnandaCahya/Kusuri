# Kebijakan Keamanan (Security Policy) 🔒

Keamanan data, privasi pengguna, dan integritas sinkronisasi adalah prioritas utama Kusuri. Kami sangat menghargai kontribusi para peneliti keamanan dan komunitas dalam menemukan dan melaporkan celah kerentanan.

## Versi yang Didukung

| Versi | Didukung? |
| :--- | :--- |
| `0.1.x` (MVP) | :white_check_mark: |
| `< 0.1.0` | :x: |

## Melaporkan Celah Kerentanan (Reporting a Vulnerability)

**JANGAN** membuat GitHub Issue publik untuk celah keamanan atau eksploitasi kritis.

Jika Anda menemukan kerentanan keamanan:
1. Laporkan secara privat melalui **GitHub Private Vulnerability Reporting** di tab "Security" repositori ini.
2. Atau kirimkan email ke: **`security@kusuri.app`**

Sertakan detail berikut:
- Ringkasan kerentanan dan potensi dampaknya.
- Langkah-langkah detail atau PoC (Proof of Concept) untuk mereproduksi temuan.
- Komponen terdampak (misal: Axum WebSocket dispatcher, JWT validation, File upload).

Kami akan merespons laporan dalam waktu maksimal **48 jam** dan memberikan pembaruan berkala hingga perbaikan resmi diterbitkan.
